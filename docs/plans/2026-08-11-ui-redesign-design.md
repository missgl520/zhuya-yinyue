# 竹笌 App UI 重新设计 · 设计文档

**日期**：2026-08-11
**依据**：用户设定文档「竹芽 2.0 设定思路」v2.2（2026-08-06）+ 用户确认项
**用户确认项**：
- 角色命名 = **竹笌**（全站统一，覆盖代码内「竹芽」残留）
- 页面范围 = **保留全部功能页**，视觉统一到设定文档的「简约少年系」
- 视觉风格 = 设定文档的 **简约少年系 · 白底 + 嫩绿 + 暖黄**

---

## 1. 目标

将现有 7 个界面（启动 / 聊天 / 语音通话 / 记忆历史 / 设置 / 菜单 / 法律）的视觉语言统一到设定文档的「简约少年系」，并把**聊天页**从「右下浮动 Live2D + 不透明信纸列表」改造为「Live2D 铺满背景 + 消息半透明浮层（虚线边框）」，让竹笌成为每个页面的视觉主角。

**不改**：后端契约/接口、HMAC 签名鉴权、静态加密（Fernet/AES）、合规同意门逻辑、Live2D 模型文件、现有 Riverpod/go_router 架构。不破坏现有可跑通的 Release 构建。

---

## 2. 设计原则（来自设定文档，已确认）

- **调性**：温暖的、像真人在陪你的 AI 朋友；语音优先、文字辅助；少年感·阳光·直接。
- **视觉风格**：简约少年系 —— 白底 + 亮色点缀，干净直接。
- **页面结构**：启动页 + 聊天页为核心；菜单 / 设置为弹层（无独立设置页）。
- **角色名**：竹笌（全站统一）。

---

## 3. 视觉规范（Design Tokens）

### 3.1 配色（严格按设定文档，废弃此前错误的珊瑚/薄荷/深棕）

| 用途 | 色值 | 说明 |
|---|---|---|
| 主色 嫩绿 | `#8BC34A` | 主按钮、强调、图标 |
| 深竹绿 | `#6B9E78` | 状态字、发送键、左边线、次级强调 |
| 强调 暖黄 | `#FFD54F` | 阳光感点缀、用户气泡 |
| 背景 米白 | `#FAFAFA` | 页面底色、卡片底 |
| 文字主 | `#212121` | 正文 |
| 文字副 | `#757575` | 辅助说明 |
| 错误 | 系统 Red | 出错徽章（沿用现状） |

- 暗色主题：背景保留 `#1A1A2E`，文字反白；嫩绿/暖黄提亮适配（在 `app_theme.dart` 内定义）。
- 语义透明层：主色 `withOpacity(0.12)` 用于状态 pill / 标签底。

### 3.2 圆角

- 8（小组件 / 标签）· 12（卡片）· 16（大卡片）· 20（气泡 / 主按钮）

### 3.3 间距

- 4pt 基准网格；页面边距 20 / 24；组件间距 8 / 12 / 16。

### 3.4 字阶

- 品牌字 18–36 / 600（带 `letterSpacing` 营造书卷气）
- 标题 18 / 500 · 正文 14 / 400 · 辅助 12 / 400

### 3.5 动效

- 统一缓动 `easeOutCubic`；时长 200–400ms。
- Logo 心跳脉冲（呼吸灯，300ms 过渡）表示「在线/活着」，离线变灰。
- Live2D 状态切换淡入淡出；页面过渡沿用淡入 + 上滑。

### 3.6 组件库（统一复用）

- **AI 消息气泡**：白底 + 嫩绿虚线左边线 / 虚线边框 + 角色小头像 + 「AI 生成」标签。
- **用户消息气泡**：暖黄 `#FFE8A8` 圆角胶囊（右对齐）。
- **主按钮**：嫩绿填充、圆角 20。
- **状态徽章**：pill，主色 12% 底 + 主色字，旁带呼吸小圆点。
- **卡片**：白底 + 0.5px 边框 + 大圆角（菜单项 / 关系卡片 / 设置组）。
- **开关 / 单选**：统一 Material3 `Switch` / `Radio`，track 用主色。

## 4. 各页面改造方案

### 4.1 启动页（splash_page.dart）

- **现状**：竹子 Logo + 竹叶飘落动效 + 品牌名「竹 笌」+ Slogan + 居中 `AlertDialog` 同意门。
- **改造**：保留 Logo 与品牌名，去掉多余飘落装饰，更克制；同意门从 `AlertDialog` 改为**全屏品牌卡片**（隐私 / 协议两栏 + 主按钮），不挡视觉；加载态用 Logo 心跳。
- **不改**：合规同意逻辑、`_legalVersion`、Hive 写入。

### 4.2 聊天页（chat_page.dart）★ 核心改造

- **现状**（第 194–232 行）：Stack 内 `Positioned(bottom:160, right:20)` 右下小 Live2D（非 idle 时 opacity 0.4）+ `Positioned.fill` 不透明消息列表（盖住 Live2D）。
- **目标（按设定文档）**：
  - **Live2D 铺满背景**：`ZhuaLive2DWidget` 改为占满整个 Stack 的底层（不再是右下小图），作为视觉主角。
  - **消息半透明浮层**：叠在 Live2D 之上，背景改为主色约 6% 透明 + 嫩绿虚线边框（`BoxDecoration`：透明 `color` + `border: Border.all(dashed, 嫩绿)`），让人物露出。
  - 顶栏：左 `竹笌▼`（菜单）/ 中 状态文字 + Logo 心跳点 / 右 `⚙️`（设置）—— 结构不变，色值统一为 `#6B9E78`（状态）/`#8BC34A`（发送）。
  - 输入区：`🎤 语音 | 输入框（圆角 20，聚焦嫩绿边框）| ＋（展开图片/相册/文件夹）| ➤ 发送` —— 结构不变，配色统一。
  - 状态机 `idle→thinking→writing→speaking` → Live2D 状态映射保持不变。
- **关键实现点**：Stack 顺序 = Live2D（底）→ 消息半透明浮层（中）→ 输入区（最上）；非 idle 时 Live2D 保持可见（去掉或弱化 0.4 透明）。

### 4.3 菜单面板（menu_panel.dart）

- **现状**：关系状态横幅 + 列表（Live2D 模型 / 角色设定 / 唤醒词 / 语音通话 / 记忆管理 / 好感度）。
- **改造**：关系状态横幅升级为**关系卡片**（竹笌头像 + 好感度环形进度 + 连续天数 + 当前情绪 emoji）；列表项统一为带图标圆角卡片；角色设定从 `onTap:null` 改为可编辑；按「身份 / 关系 / 记忆 / 角色」分组。
- 配色：卡片白底 + 0.5 边框，图标嫩绿。

### 4.4 设置 Sheet（settings_sheet.dart）

- **现状**：关于 / 声音 / 语音 / 模型 分组。
- **改造**：分组卡片化（图标 + 标题 + 副标题行）；开关 / 单选统一为 Material3；模型国际版跨境传输确认更醒目；保留底部安全距离。

### 4.5 语音通话页（voice_call_page.dart）

- **改造**：中央大头像（竹笌 Live2D 或静态）+ 环形声波可视化；控制按钮（静音 / 挂断）悬浮毛玻璃；计时优雅；上下布局避免遮挡。

### 4.6 记忆历史页（memory_history_page.dart）

- **改造**：记忆卡片（角色 / 时间 / 标签 chips）；搜索框升级（带图标圆角框，保留内存解密过滤）；空状态插画。
- **顺带清理**：第 194 行正则 `RegExp(r'^(用户|竹芽|竹笌|User|AI)[:：]\s*')` 中的「竹芽」移除。

### 4.7 法律页（legal_page.dart）

- **改造**：纯文本美化（标题层级、段落间距、可滚动）；返回栏；长文阅读舒适度。内容仍来自后端 `/legal`，不改后端。
