# 竹笌/Ren · VRoidStudio 2.14.0 3D 化设计规范

> **用途**：在 VRoidStudio 2.14.0 中复刻竹笌 App 的虚拟角色 Ren 的 3D 版本（VRM 模型）。
> **来源**：`assets/live2d/ren/Ren.2048/texture_00.png` + 应用截图 + UI 设计文档。
> **风格关键词**：简约少年系、阳光 AI 朋友、现代街头风、动漫少年。

## 2. 面部与五官

### 2.1 脸型
- **脸型**：鹅蛋偏尖，下巴略尖，脸颊微收，不婴儿肥。
- **VRoid 建议**：选默认少年脸，调小脸颊肉感，下巴稍微拉长/收窄。

### 2.2 眼睛
- **眼型**：杏眼，眼尾微微上扬，双眼皮窄。
- **瞳色**：浅蓝灰/冷蓝色，明度中高，像晴天天空。
- **高光**：眼睛上半部分有白色小高光，显得有神。
- **睫毛**：上睫毛明显但不过长，下睫毛细少。
- **眉毛**：深灰黑色，自然眉形，略平直。
- **腮红**：轻微桃粉色，只在脸颊中部淡淡的。

### 2.3 嘴与鼻
- **鼻子**：小且低，只画鼻尖小阴影。
- **嘴**：小嘴，唇色接近肤色，平时自然闭合。

### 2.4 肤色
- **主色**：`#FCE4D6` / `#FFE8D6` 偏暖的浅肤色。
- **阴影**：略带粉红的 `#F5C6B8`。
- **VRoid 建议**：材质 `Toon`，一级阴影偏粉，二级阴影偏棕灰，不要过浓。

## 3. 发型

### 3.1 主发型
- **长度**：中长，后颈到衣领，侧发遮耳，刘海在眉眼之间。
- **层次**：上层短、下层长，后脑勺蓬松，发尾微翘。
- **风格**：少年感的碎发，不油不贴，微微凌乱。

### 3.2 发色
- **主色**：深灰黑色 `#2E2E2E`（可偏一点冷棕）。
- **挑染/渐变**：耳侧/后发尾有一段明显的青蓝色 `#5D8A99`/`#6FA8B8`，作为角色记忆点。
- **刘海/内侧**：隐约可见少量暗红/酒红 `#7A2E2E` 发束（可选，根据原贴图细节）。

### 3.3 VRoid 头发建议
- **基础**：使用「短发少年」类预设，稍作打散。
- **发束**：前额分 5–7 束，两侧 3–4 束，后脑勺 4–6 束，整体蓬松。
- **渐变**：后发尾发束单独设青蓝色；刘海内侧可设一暗红色束。
- **光泽**：Toon 材质，高光弱，偏向哑光。

## 4. 服装（全身）

> VRoidStudio 自带服装模板有限，复杂外套建议在 Blender/Marvelous 中做或在 VRoid 中用「服装纹理」贴出大效果。本规范按 VRoid 2.14.0 可用流程描述。

### 4.1 外套：白色连帽夹克
- **主色**：米白/纯白 `#F5F5F5` ~ `#FFFFFF`。
- **内衬/帽里**：暖黄/橘黄 `#FFD54F`/`#FFC107`。
- **装饰线**：正面两条竖向金黄色细条 `#FFC107`，从领口到下摆。
- **袖带**：上臂有一圈黑色宽环带，带金属扣 `#333333`。
- **胸前口袋/拉链**：黑色小矩形装饰在左胸。
- **拉链/金属件**：银灰 `#C0C0C0`。
- **版型**：略宽松的中长款夹克，落肩，袖口稍收。

### 4.2 内搭：黑色交叉纹 V 领衫
- **主色**：深灰黑 `#2A2A2A`。
- **图案**：胸前两道白色粗斜线交叉成「X」形 `#FFFFFF`。
- **领口**：深 V 领，露出锁骨上方一点皮肤。
- **VRoid 建议**：如果做不出来双层，直接用 VRoid 的「T恤/卫衣」模板，贴图方式画 X 纹；外套用另一件上衣覆盖。

### 4.3 裤子
- **主色**：深炭灰/黑色 `#2E2E2E`。
- **款式**：修身工装/束脚裤，膝盖处有一道横向拼接线或微鼓起。
- **裤脚**：略收紧，塞入短靴内。

### 4.4 鞋子：黑色短靴
- **主色**：黑色 `#1A1A1A`。
- **鞋底/鞋头包边**：暖黄 `#FFC107`/`#E6A428`。
- **装饰**：鞋帮两侧有银色圆片/搭扣，鞋带孔和侧面带扣。
- **款式**：中高帮马丁靴风格。

### 4.5 配饰
- **项链**：黑色细绳，挂一个银色小三角吊坠 `#C0C0C0`，长度到胸口。

## 6. VRoidStudio 2.14.0 操作建议

### 6.1 起始预设
1. 新建角色 → 选 **Male / 少年体型**。
2. 身体比例：身高约 165–172cm 感，偏瘦，肩宽中等。
3. 头身比：大约 1:6.5–7，保留动漫感。

### 6.2 脸部参数
- 脸长：稍微拉长。
- 脸颊：向内收，避免圆润。
- 下巴：尖一点，但不过 V 字。
- 眼睛位置：略偏下（显年轻），眼间距略宽。
- 嘴：小，位置偏下。
- 眉毛：平直少年眉，颜色深灰黑。

### 6.3 头发参数
- 用「短发」预设做底，再拆分多发束调整。
- 刘海分为 5 束，中间短、两侧略长遮眼。
- 后发做两层：上层蓬松、下层青蓝色渐变。
- 发梢向外翘，增加少年随意感。

### 6.4 服装纹理建议
- VRoid 2.14.0 的服装系统以基础模板 + 贴图为主。
- **最省时间做法**：
  - 上身：用「长袖外套」模板，主体白色，内衬暖黄，导出 UV 后在 Photoshop 中画金色竖条、黑色袖带、口袋、拉链。
  - 内搭：单独一件「短袖 T 恤」或直接用贴图画出领口和 X 纹（在夹克贴图上留出 V 领区域）。
  - 下身：用「长裤」模板，深灰黑色，膝盖处画一道拼接阴影。
  - 鞋子：用「短靴」模板，黑色主体 + 黄色鞋底包边，侧面画银扣。
- 纹理导出路径：VRoid Studio → 服装 → 编辑纹理 → 导出 PNG → 修改 → 重新导入。

### 6.5 材质与光影
- 所有材质统一用 **Toon（卡通渲染）**，配合 App 内 Live2D 的扁平动漫感。
- 阴影颜色不要过黑，偏暖灰或偏粉。
- 高光面积小、柔和，头发和外套尤其要弱化反光。

### 6.6 导出设置
- 导出格式：**VRM 0.x / 1.0**（按你的目标平台选择）。
- 贴图分辨率：建议 1024×1024 或 2048×2048。
- 导出前检查：面部法线、头发穿插、服装穿模、骨骼权重。

## 7. 与现有 2D 角色的差异提示

| 维度 | 2D Live2D 现状 | 3D 化注意 |
|---|---|---|
| 眼睛 | 手绘高光明显 | VRoid 可用贴图眼睛 + 手绘高光层 |
| 头发 | 深色底 + 青蓝渐变 + 暗红挑染 | 发束颜色分开设置，渐变可用顶点色/贴图 |
| 服装 | 多层叠穿、图案复杂 | 建议贴图法，先保证大色块和 X 纹、黄条正确 |
| 比例 | 动漫长腿 | VRoid 默认偏写实，手动调头身比 |
