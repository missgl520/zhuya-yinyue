### 2. ClientAuth 默认值清空

当前 `defaultValue: 'zhuyu-dev-key-change-me'` 有误导风险，改为抛异常：

```dart
static String get apiKey {
  final key = const String.fromEnvironment('ZHUYU_API_KEY', defaultValue: '');
  if (key.isEmpty) {
    throw StateError('请通过 --dart-define=ZHUYU_API_KEY=*** 传入后端密钥');
  }
  return key;
}
```

## 🟡 P1 - 本周做

### 4. 废弃 legacy providers（来自 MVVM 文章）

**问题：** `lib/providers/app_providers_legacy.dart`（442行）与 `presentation/providers/` 双轨运行，chat_page.dart 同时引用两套。

**目标：** 迁移完成后只保留 `presentation/providers/`

迁移清单：
- `themeProvider` → `presentation/providers/theme_provider.dart`（新建）
- `apiKeyProvider` → `presentation/providers/settings_provider.dart`（新建）
- `agnesServiceProvider` → 确认是否仍需（旧架构直连已废弃）
- `messagesProvider` → ChatNotifier 已接管，确认是否可删
- `ttsEnabledProvider / ttsModeProvider` → settings_provider.dart
- `cartesiaTtsServiceProvider / miniMaxTtsServiceProvider` → 确认是否还在用

**验收：** 搜索 `old_providers` 确认全项目无残留引用。

### 5. Flutter SDK 升级到 3.16+

**原因：** `iconmind_flutter` 要求 `flutter >= 3.16.0`，当前 3.12.2 不满足。

**风险点：**
- `go_router` 版本兼容性
- `livekit_client` 兼容性
- 确认 `model_viewer_plus` 和 `flutter_live2d` 兼容 3.16

**步骤：**
1. `flutter upgrade` 或手动改 `pubspec.yaml` 的 `sdk: ^3.16.0`
2. `flutter pub upgrade`
3. 跑 `flutter analyze` 检查 breaking changes
4. 全流程测试（对话/TTS/换装/语音通话）

### 6. 加 iconmind_flutter 图标库

升级 Flutter 3.16+ 后，在 `pubspec.yaml` 加：

```yaml
dependencies:
  iconmind_flutter: ^0.6.0
```

**适用场景：** AI 菜单图标（Agents/Models/Knowledge Base/MCP/Tools 等），替换目前只有 `cupertino_icons` 的状态。
